# МегаВольт24

Статический каталог электроинструмента для GitHub Pages: поиск, фильтры, карточки товаров и оформление заказа в Telegram.

## Что внутри

- `index.html` — страница каталога.
- `assets/style.css` — оформление.
- `assets/app.js` — поиск, фильтры, сортировка, карточка товара.
- `data/products.js` — данные каталога (генерируются из JSONL).
- `tools/build_data.py` — сборка данных.
- `.nojekyll` — отключает Jekyll на GitHub Pages.

## Заказ

Кнопка «Купить» ведёт в Telegram к менеджеру [@yunkers0](https://t.me/yunkers0). В сообщение автоматически подставляются артикул, название, цена и количество.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него **содержимое** этой папки (файлы должны лежать в корне репозитория).
2. Откройте `Settings → Pages`.
3. В разделе `Build and deployment` выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
4. Сохраните и дождитесь публикации.

## Обновление каталога

Положите новый `catalog_products_priced.jsonl` и выполните:

```bash
python3 tools/build_data.py /путь/к/catalog_products_priced.jsonl
```

Скрипт перезапишет `data/products.js`. Если файл лежит по стандартному пути `/home/kitty/Documents/Parse/catalog_products_priced.jsonl`, путь можно не указывать.

## Локальный просмотр

Можно просто открыть `index.html` в браузере или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть <http://localhost:8000>.

## Примечание

Фотографии товаров загружаются с внешнего сервера по прямым ссылкам. Цены и наличие указаны по данным каталога — перед оформлением их подтверждает менеджер.
